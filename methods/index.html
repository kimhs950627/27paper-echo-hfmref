측정오차를 어떻게
숫자로 만드는가

“EF는 흔들린다”는 말은 논문이 아니다. 얼마나 흔들리는지, 어떤 판정이 흔들리는지, 그리고 다시 재면 얼마나 달라지는지를 추정하는 순서를 적는다.

TTE 179,928검사 · LVEF 133,841 · 재측정 쌍 12,522(30일) / 27,576(180일)

설계 요약

  1. σ를 짧은 간격 재측정으로 분리한다(진짜 변화 ≈ 0).
  2. 재현율을 정의한다 — 같은 판정이 다시 나올 경험적 확률. 가정이 없다.
  3. 종점을 치료 문턱(40/50) 교차로 정의한다.
  4. 모형은 직전 검사만 입력해 누수를 막고, 환자 단위로 검증한다.
  5. 선별 효율로 임상적 쓸모를 확인한다(NNR·포착률).

01잡음 분리 — 왜 짧은 간격인가

관측값 = 참값 + 잡음이라 하면 두 측정의 차이는 두 잡음의 차이다. 독립이면 분산이 더해진다.

분산분해 Var(ΔEF) = 2σ² + Var(진짜 변화)  →  짧은 간격이면 Var(ΔEF) ≈ 2σ² σ = SD(ΔEF) / √2. 30일 창에서 SD(Δ)=10.49 → σ = 7.41.

이 가정은 데이터로 검증된다: 30일 내 쌍의 평균 ΔEF = +0.33%p로 0에 가깝다. 같은 계산을 간격별로 반복해도 ΔSD가 8.2–10.2로 거의 변하지 않는다 — 1년 안의 실제 변화는 잡음에 묻힌다.

밴드별 추정 (30일 창) <30: 7.56 · 30–39: 7.41 · 40–49: 6.75 · 50–59: 5.79 · ≥60: 6.20 보수적으로 7.41을 전 구간에 적용한다. 낮은 EF에서 더 크므로 과소추정이 아니다.

02신뢰도와 감쇠 — 왜 R²가 0.11인가

관측 EF의 분산은 참값 분산(τ²)과 잡음 분산(σ²)의 합이다. 신뢰도는 그중 참값 몫이다.

신뢰도 λ = τ² / (τ² + σ²) = 106.4 / (106.4 + 54.9) = 0.66 관측 EF 분산 161.3(SD 12.7)에서 참값 몫은 66%, 잡음이 34%.

감쇠(attenuation) 때문에 관측값끼리의 상관은 참값 상관의 λ배로 줄어든다. 그래서 관측 EF로 다음 EF를 예측하는 모형의 이론적 R² 상한은 0.66이다. 실제로 선형 0.112, GBM 0.102였다 — 상한보다 훨씬 낮은데, 그 이유는 참 EF 자체가 시간에 따라 잘 예측되지 않기 때문이다(회귀평균). 이 사실이 “EF 값을 예측하는 모델”을 포기한 근거다.

회귀평균: 기준선을 낮은 값으로 고르면 다음 값은 평균 쪽으로 올라간다. E[참값|관측] = μ + λ(관측 − μ). EF 30을 고르면 참값 기대는 30이 아니라 더 높다.

04종점 — 치료 문턱 교차

3분류(40/50)의 경계가 곧 치료 문턱이므로 범주 변화는 자동으로 임상 문턱 교차가 된다. ICD 문턱(<35)은 2차 종점으로 둔다.

해석 주의 이 종점은 측정 불안정성이지 환자 악화가 아니다. “재측정 시 판정이 뒤집힌다”로만 서술한다. 30일 창에서는 진짜 변화가 거의 0이므로 사실상 “잡음으로 라벨이 뒤집힘”을 측정한다.

05특징과 누수 — 0.841은 틀린 값이었다

초기 구현은 현재 검사의 LVEDD·심박수를 입력에 넣어 AUC 0.841을 얻었다. 그 값들은 종점 EF와 같은 시점에 측정되므로 미래 정보가 새어 들어간 것이다. 직전 검사 값만 쓰도록 고친 뒤 0.824가 됐다. 0.017이 정직한 성능과 부풀린 성능의 차이다.

입력 (직전 검사만)

직전 EF, 문턱까지 거리, 간격(일), 직전 LVEDD·LVOT VTI·TR velocity·심박수·수축기혈압·체표면적, 연도

현재 검사에서 파생된 어떤 값도 넣지 않는다.

결측 처리

중앙값 대체 + 결측 지시자 10개를 별도 변수로 추가. 최대 결측은 LVOT VTI 64%이며, 결측 여부 자체가 검사 프로토콜의 정보를 담는다.

06검증 — 환자 단위로 자른다

한 환자가 여러 쌍을 만들기 때문에 무작위 분할하면 낙관적 편향이 생긴다. GroupKFold(5)로 환자 단위 분할하고 out-of-fold 예측으로 AUC·Brier를 계산한다.

07선별 효율 — 임상적 쓸모

AUC는 “줄 세우기” 성능이고, 임상에서 필요한 것은 “몇 명을 다시 재면 몇 건을 잡는가”다.

다시 잴 비율포착률PPVNNR
상위 10%33.3%57.5%1.7
상위 20%58.3%50.3%2.0
상위 30%74.6%42.9%2.3
전체100%17.2%5.8

전체 재검 대비 상위 20% 전략의 효율은 약 2.9배(NNR 5.8 → 2.0)다. 이 수치가 “모든 환자 재검”이라는 비현실적 처방을 피하게 해준다.
