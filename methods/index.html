측정오차를 어떻게
숫자로 만드는가

“EF는 흔들린다”는 말은 논문이 아니다. 얼마나 흔들리는지, 어떤 판정이 흔들리는지, 그리고 다시 재면 얼마나 달라지는지를 추정하는 순서를 적는다.

TTE 179,928검사 · LVEF 133,841 · 재측정 쌍 12,522(30일) / 27,576(180일)

순서

  1. 잡음 크기를 짧은 간격 재측정으로 분리한다 (진짜 변화 ≈ 0 가정이 성립하는 구간).
  2. 재현율을 정의한다 — 같은 판정이 다시 나올 경험적 확률. 가정이 없다.
  3. 종점을 치료 문턱 교차로 정의한다.
  4. 모형은 직전 검사만 입력해 누수를 막고, 환자 단위로 검증한다.

01잡음 분리 — 왜 짧은 간격인가

관측값 = 참값 + 잡음이라 하면, 두 번 측정의 차이는

분산분해 Var(ΔEF) = 2σ² + Var(진짜 변화) 간격이 충분히 짧으면 진짜 변화 ≈ 0이므로 Var(ΔEF) ≈ 2σ². 여기서 σ를 얻는다.

30일 이내 쌍에서 평균 ΔEF는 +0.33%p로 0에 가깝다 — 이 가정이 데이터로 지지된다. 같은 계산을 기간별로 반복하면(1–7일, 1–3개월, 6–12개월) ΔSD가 8.2–10.2로 거의 변하지 않는다. 즉 1년 안의 EF 변화는 잡음에 묻혀 검출되지 않는다.

추정치: 1회 측정 잡음 SD 7.08%p(전체), EF 30–39 구간 7.41. 이후 계산은 보수적으로 7.41을 쓴다.

02재현율 — 가정 없는 확신도

확신도를 사후확률로 정의하면 “진짜 변화의 사전분포”를 정해야 하고, 그 선택에 답이 좌우된다. 그래서 주 지표는 관측 가능한 재현율로 둔다.

정의 재현율 = P(재측정 시 같은 EF 범주 | 현재 범주) 30일 내 재측정 쌍에서 직접 센다. 분포 가정이 없다.

HFrEF (<40)2,93475.8%
HFmrEF (40–49)1,41742.5%

문턱까지 거리로도 단조롭게 갈린다: 0–2%p 62.6%, 5–10%p 77.1%, 10–30%p 91.0%. HFmrEF 판정은 다시 재면 절반 이상이 다른 범주로 간다는 것이 이 논문의 출발점이다.

03종점 — 치료 문턱 교차

3분류(40/50)의 경계가 곧 치료 문턱이므로, 범주 변화는 자동으로 임상 문턱 교차가 된다. 별도로 ICD 문턱(<35)을 2차 종점으로 둔다.

종점발생률임상 의미
40 또는 50 교차 (주)17.2%ARNI/MRA 적응, HFpEF 경계
<35 교차 (2차)8.7%ICD 상담 대상 변화
해석 주의 이 종점은 측정 불안정성이지 환자 악화가 아니다. “재측정 시 판정이 뒤집힌다”로만 서술한다.

04모형 — 누수를 먼저 막는다

초기 구현에서 현재 검사의 LVEDD·심박수를 입력으로 넣었더니 AUC가 0.841로 나왔다. 그 값들은 종점 EF와 같은 시점에 측정되므로 미래 정보가 새어 들어간 것이다. 직전 검사 값만 쓰도록 고친 뒤 AUC는 0.824가 됐다.

입력 (직전 검사만)

직전 EF, 문턱까지 거리, 간격(일), 직전 LVEDD·LVOT VTI·TR velocity·심박수·수축기혈압·체표면적, 연도

결측 처리

중앙값 대체 + 결측 지시자를 별도 변수로 추가. 결측 자체가 검사 프로토콜의 정보를 담기 때문.

모형은 랜덤포레스트(주)와 XGBoost(민감도). 하이퍼파라미터는 고정값을 썼고, 성능 차이는 fold 표준편차 안이다.

05검증 — 환자 단위로 자른다

같은 환자가 여러 쌍을 만들기 때문에 무작위 분할하면 낙관적 편향이 생긴다. GroupKFold(5)로 환자 단위 분할하고, out-of-fold 예측으로 AUC·Brier를 계산한다.

06아직 안 한 것

  • Temporal split: 연도 기준 학습/검증 분리 (외부검증 대체).
  • Conformal: 환자별 예측구간과 보장된 coverage.
  • DCA: 재측정 100건당 막은 오분류 건수로 임상 효용 계산.
  • HFimpEF 접목: ΔEF 10%p 기준이 잡음(ΔSD 10.5)보다 작다는 결과와 연결.

수학(분산분해·신뢰도·ROC)은 수학 노트에 따로 정리했다.
