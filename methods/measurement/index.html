측정오차는
어떻게 숫자가 되나

분산분해, 감쇠, 회귀평균, Wilson 구간, ROC/AUC, 결정곡선, conformal. 고3 수학(표준편차·정규분포·확률)만 있으면 전부 따라올 수 있다. 모든 계산은 손으로 검산 가능한 숫자로 했다.

01참값은 한 번도 관측되지 않는다

모형 관측 EF = 참 EF + ε,   ε ~ N(0, σ²) ε의 평균은 0, 표준편차는 σ. σ가 작으면 관측값을 믿고, 크면 다시 재야 한다.

문제는 σ를 모른다는 것. σ를 알면 관측값 x에서 참값이 어느 구간에 있을 확률을 바로 계산할 수 있다.

정규분포 계산 P(참값 < c | 관측 x) = Φ((c − x) / σ) Φ는 표준정규 누적확률. Φ(−0.135) = 0.446, Φ(0.27) = 0.606.
손계산 — EF 41에서 참값이 40 미만일 확률 z = (40 − 41) / 7.4 = −0.135  →  Φ(−0.135) = 0.446 (44.6%)

이 숫자가 논문의 출발점이다. “EF 41이면 HFrEF”라고 말할 수 있는 확률이 55.4%밖에 안 된다는 뜻이다.

02분산분해 — σ를 꺼내는 방법

두 번 측정의 차이는 ε₂ − ε₁이고, 독립이면 분산이 더해진다.

분산분해 Var(ΔEF) = Var(ε₂) + Var(ε₁) + Var(진짜 변화) = 2σ² + τ² 짧은 간격이면 τ ≈ 0 → σ = SD(ΔEF) / √2
손계산 30일 내 쌍 12,522개의 ΔEF SD = 10.49
σ = 10.49 / 1.414 = 7.41

가정이 하나 있다: 짧은 간격에서 참값이 변하지 않는다. 검증은 평균 ΔEF로 한다. 실제 값이 +0.33%p이므로 “변화 없음”이 데이터와 모순되지 않는다.

만약 진짜 변화가 조금이라도 있으면 σ는 과대추정된다(τ²가 더해지므로). 보수적 방향이라 결론을 강하게 만든다.

03군 평균은 9명으로 검출된다 — 개인 판정은 안 된다

많이 헷갈리는 지점이라 따로 적는다. “EF가 10%p 변했다”를 군 평균으로 검출하는 데 필요한 표본수는

표본수 n = 2(z1−α/2 + z1−β)² σ² / δ² δ=10, σ=7.4, α=.05, power=.8 → n = 2(1.96+0.84)²(54.8)/100 = 8.6 → 9쌍

즉 9명만 있어도 평균 10%p 상승은 통계적으로 검출된다. 그런데 개인 한 명의 판정은 전혀 다르다. 개인에서는 σ√2 = 10.5가 그대로 남아, 관측 Δ가 10이면 참값이 10 이상일 확률이 50%밖에 안 된다.

구분 “군 평균의 차이 검출”과 “개인 판정”은 다른 문제다. 임상 논문이 전자를 보여주면서 후자를 주장하는 경우가 많다.

04신뢰도·감쇠·회귀평균

신뢰도 λ = τ² / (τ² + σ²) = 106.4 / 161.3 = 0.66 관측 EF 분산 161.3(SD 12.7), 잡음 분산 54.9(σ=7.41²).

감쇠: 관측값끼리의 상관은 참값 상관의 λ배로 줄어든다. 그래서 관측 EF로 다음 EF를 예측하는 모형의 R² 상한은 0.66이다. 실제 0.11이었다.

회귀평균 (Bayes) E[참값 | 관측 x] = μ + λ(x − μ) μ=55, λ=0.66이면 x=30 → E[참값]=55+0.66(30−55)=38.5

EF 30을 관측한 환자의 참값 기대는 30이 아니라 38.5다. 그래서 “낮은 EF를 고른 뒤 다음 값을 보면 올라간다”는 현상이 생기고, 이걸 회복으로 오독하면 안 된다.

05재현율과 Wilson 구간

재현율은 그냥 세는 확률이다. 문제는 신뢰구간이다. 비율이 0이나 1에 가까울 때 정규근사(Wald)는 망가지므로 Wilson을 쓴다.

Wilson 95% CI (p̂ + z²/2n ± z√(p̂(1−p̂)/n + z²/4n²)) / (1 + z²/n) z=1.96. HFmrEF 42.5%, n=1,417 → 40.0–45.1%
손계산 (HFmrEF) p̂=0.425, n=1417
√(0.425×0.575/1417 + 3.84/(4×1417²)) = √(0.0001725 + 0.0000005) = 0.01315
반폭 = 1.96 × 0.01315 / (1+0.0027) = 0.0257 → 39.9–45.1%

HFrEF 75.8%(n=2,934) → 74.2–77.3%, 정상 92.2%(n=8,171) → 91.6–92.8%. 세 구간이 겹치지 않으므로 “HFmrEF만 불안정하다”는 주장은 표본오차로 설명되지 않는다.

06ROC·AUC — 문턱을 정하지 않는 지표

AUC AUC = P(사건 환자의 예측확률 > 비사건 환자의 예측확률) 0.5 = 동전, 1.0 = 완벽. “무작위로 뽑은 두 사람을 옳게 줄 세울 확률”.

표준오차는 DeLong 법으로 구한다. 이 데이터에서는 fold 표준편차가 0.011–0.017이라 랜덤포레스트(0.824)와 XGBoost(0.824)의 차이는 유의하지 않다.

DeLong (개념) SE² = Var(V₁₀)/n₁ + Var(V₀₁)/n₀ V는 각 개인의 “짝지은 상대보다 높을 확률”. 구현은 스크립트에서.

AUC가 높아도 임상 효용은 별개다. 그래서 보정(Brier)과 결정곡선을 함께 본다.

07결정곡선 — 재검의 순이득

순이득(Net benefit) NB = TPR·π − FPR·(1−π)· pt/(1−pt) π는 유병률, pt는 “이 확률 이상이면 재검한다”는 문턱.
손계산 — pt=0.30, π=0.172 전부 재검: NB = 0.172 − 0.828 × (0.3/0.7) = 0.172 − 0.355 = −0.183
상위 20%만: 선택군 PPV 0.503 → 선택군 NB = 0.503 − 0.497×0.4286 = 0.290
전체 환자당 NB = 0.20 × 0.290 = +0.058

문턱 30%에서 “전부 재검”은 순이득이 음수다(불필요한 재검이 이득을 덮음). 상위 20%만 재검하면 양수가 된다. 이게 선별 모델의 존재 이유다.

08Conformal — 분포 가정 없는 예측구간

모형이 “확률 62%”라고 할 때, 그 62%가 얼마나 믿을 만한지는 별개다. 분할 conformal은 보정셋에서 비순응도 점수를 모아 분위수를 잡는다.

분할 conformal q = Quantile⌈(n+1)(1−α)⌉/n( { 1 − p̂(yi | xi) } )
예측집합 C(x) = { y : 1 − p̂(y|x) ≤ q } α=0.1이면 새 환자의 참 라벨이 C(x)에 들 확률이 최소 90%로 보장된다(교환가능성 가정).

이 프로젝트에서는 두 가지에 쓸 예정이다: (1) 재분류 확률의 구간, (2) “재검 필요/불필요” 판정의 보장된 집합. 시계열 데이터라 교환가능성이 깨질 수 있으므로 시간 순서 블록으로 보정셋을 잡는다.

09함정 일곱 개

  1. 누수 — 종점과 같은 시점에 측정된 값을 입력에 넣으면 AUC가 부푼다(0.841 → 0.824).
  2. 환자 단위 분할 — 같은 환자의 쌍이 학습·검증에 나뉘면 성능이 과대평가된다.
  3. 선택편향 — 재검을 받은 사람만 학습한다. 일반 외래와 다를 수 있다.
  4. 회귀평균 — 낮은 기준선을 고르면 다음 값이 평균으로 올라간다. 개선처럼 보인다.
  5. 시간과 잡음의 혼동 — 30일과 180일 사건률이 같다는 사실을 확인하지 않으면 진행으로 오독한다.
  6. 군 평균 vs 개인 — n=9로 평균 차이는 검출되지만 개인 판정은 불가능하다.
  7. 자릿수 선호 — 판독자가 5의 배수로 적어 Δ 분포가 이산적이 된다(Δ=10이 18.9%).
