분산분해, 신뢰도, 재현율, ROC. 고3 수학(표준편차·정규분포·확률)만 있으면 전부 따라올 수 있다. 100명짜리 장난감 예시로 손계산부터 한다.

01우리는 참값을 한 번도 본 적이 없다

심초음파로 재는 EF는 참값이 아니라 참값 + 잡음이다. 같은 사람을 다시 재면 값이 달라지는데, 그게 “심장이 변했다”인지 “기계가 흔들렸다”인지 우리는 알 수 없다.

모형 관측 EF = 참 EF + ε,   ε ~ 평균 0, 표준편차 σ σ가 작으면 관측값을 믿고, 크면 다시 재야 한다.

문제는 σ를 모른다는 것. 그래서 간격을 짧게 해서 참값이 변하지 않게 만든 뒤 차이를 본다.

02차이의 분산 = 잡음 두 개

두 번 측정의 차이는 ε₂ − ε₁이다. 독립이면 분산이 더해진다.

분산분해 Var(ΔEF) = Var(ε₂) + Var(ε₁) + Var(진짜 변화) = 2σ² + τ² 짧은 간격이면 τ ≈ 0 → Var(ΔEF) ≈ 2σ² → σ = SD(ΔEF)/√2
손계산 30일 내 쌍에서 ΔEF의 표준편차가 10.49라면
σ = 10.49 / 1.414 = 7.41

03σ가 7.4면 무엇이 문제인가

HFimpEF 기준은 “EF가 10%p 이상 올랐는가”다. 그런데 Δ의 잡음 표준편차는 σ√2 = 10.5다. 기준(10)보다 잡음(10.5)이 크다.

확신도 P(진짜 Δ ≥ 10 | 관측 Δ) = Φ((관측 Δ − 10) / 10.5) Φ는 표준정규 누적확률. 관측 Δ=10이면 50%, 20이면 83%, 25면 92%.

15%p68%
20%p83%
25%p92%

이 계산은 “진짜 변화의 사전분포”를 쓰지 않은 단순 버전이다. 사전분포를 넣으면 확신도가 더 낮아진다.

04신뢰도 — 관측 분산 중 참값 몫

신뢰도 λ = τ² / (τ² + σ²) 관측 EF 분산 161.3, σ²=54.9 → τ²=106.4 → λ = 0.66

관측 EF가 흔들리는 것 중 34%는 잡음이라는 뜻. 그래서 관측 EF 하나로 예측하는 모형의 설명력(R²)은 이론적으로 0.66을 넘을 수 없다. 실제로 선형·GBM 모두 R² 0.11이었다 — 훨씬 낮은데, 그 이유는 참 EF 자체가 다음 값을 잘 예측하지 못하기 때문이다.

05재현율 — 가정 없이 세는 확률

위 계산은 모두 정규분포를 가정한다. 가정을 없애려면 그냥 세면 된다.

예 30일 내 재측정 쌍 1,417개 중 첫 검사가 HFmrEF(40–49)였던 것 = 1,417
그중 두 번째도 40–49였던 것 → 재현율 42.5%

이 숫자는 모형도 분포도 필요 없다. 대신 “30일 안에 다시 잰 사람”이라는 조건이 붙는다.

06ROC와 AUC — 문턱을 안 정해도 되는 지표

모형은 0~1 사이 확률을 내놓는다. 어디서 자를지(문턱) 정하면 민감도와 특이도가 갈린다. ROC는 모든 문턱을 한 번에 그린 곡선이다.

AUC AUC = P(사건 환자의 예측확률 > 비사건 환자의 예측확률) 0.5 = 동전, 1.0 = 완벽. “무작위로 뽑은 두 사람을 옳게 줄 세울 확률”이다.
모형AUC해석
거리 규칙0.703문턱에 가까울수록 위험 — 그것만 씀
로지스틱0.791변수를 선형으로 결합
랜덤포레스트0.824비선형 상호작용까지 사용

AUC가 높다고 임상적으로 유용한 것은 아니다. 그래서 보정(Brier)과 결정곡선(DCA)이 함께 필요하다.

07함정 다섯 개

  1. 누수 — 종점과 같은 시점에 측정된 값을 입력에 넣으면 AUC가 부풀려진다(0.841 → 0.824).
  2. 환자 단위 분할 — 같은 환자의 쌍이 학습·검증에 나뉘면 성능이 과대평가된다.
  3. 선택편향 — 재검을 받은 사람만 학습한다. 일반 외래와 다를 수 있다.
  4. 회귀평균 — 기준선을 낮은 값으로 고르면 다음 값이 평균 쪽으로 올라간다. 개선처럼 보인다.
  5. 시간과 잡음의 혼동 — 30일과 180일의 사건률이 같다는 사실을 확인하지 않으면 진행으로 오독한다.
